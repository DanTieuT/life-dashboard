## 007 — what's left

`.cat-bar-fill`, `.goal-bar-fill`, `.proj-prog-fill`, `.spend-total-fill`,
`.runway-fill` were converted to `transform: scaleX()`. `.payday-fill` was left
on `width` (its `linear-gradient(90deg)` would squash under scale, not clip).
`.budget-bar-fill` has no JS setter (unused) — left as-is.

`.mini-bar` (`js/dashboard.js:428`) and `.trend-bar` (`js/finance.js:1474`) set
`height:${h}px` where `h` is already an absolute pixel value inside a
fixed-height chart container (`.mini-chart` 36px, `.trend-chart` 80px). Per this
plan's own boundary these were left for a follow-up: convert to
`transform: scaleY(h / containerHeight)` with `transform-origin: bottom` and the
bar at `height: 100%`.
